# 🐿️ 늘감사합니다람 (ThankSquirrel)

https://thanksquirrel.pages.dev/

> **"다람다람! 용기를 내어 와 주셔서 감사합니다람!"**
> 바쁜 일상 속에서 따뜻함과 위로가 필요할 때, 친근한 다람쥐 캐릭터 **'달램이(Dalaemi)'**가 전하는 소중한 편지를 받아보세요. 

**늘감사합니다람(ThankSquirrel)**은 사용자가 매일 한 번씩 귀여운 다람쥐 캐릭터 달램이로부터 따뜻하고 위로가 되는 "랜덤 편지"를 출석 보상처럼 받고, 달램이와 다양한 모션 및 마우스 드래그/클릭으로 실시간 상호작용할 수 있는 힐링형 반응형 웹 애플리케이션입니다.

## 🌟 프로젝트 개요
* **서비스명**: 늘감사합니다람 (ThankSquirrel)
* **컨셉**: 따뜻하고 친근한 말투의 다람쥐 캐릭터 '달램이'가 상주하는 힐링 공간.
* **주요 플로우**:
  1. **인터랙티브 로그인/회원가입**: 입력창 포커스 및 작성 상태에 따라 달램이가 눈을 가리는 등 실시간 비주얼 피드백 제공.
  2. **일일 편지 수령 (출석체크)**: 매일 최초 로그인 시 한국 표준시(KST) 기준으로 하루에 한 번 달램이가 물어다 주는 편지 개봉.
  3. **달램이와의 상호작용**: 쓰다듬기(드래그), 간지럽히기, 도토리 먹이기, 도토리 뺏기 등 마우스 인터랙션을 통한 감정 반응.
  4. **편지 보관함**: 지금까지 수령한 편지들을 한눈에 확인하고, 검색 및 필터링하여 다시 읽기.

## 🛠️ 기술 스택 (Tech Stack)

### Frontend
* **React 19**: 최신 React 아키텍처 기반의 컴포넌트 설계 및 상태 관리.
* **Vite**: 초고속 빌드 도구 및 개발 환경 구축.
* **Vanilla CSS**: 프레임워크 없는 순수 CSS 활용, 커스텀 트랜지션 및 트랜스폼 애니메이션 구현.
* **browser-image-compression**: 마이페이지 프로필 업로드 시 100KB 이상의 이미지를 자동으로 최적화/압축 처리.

### Backend & Database (Serverless)
* **Cloudflare Workers**: 서버리스 API 구현을 통해 편지 목록을 제공하고 연동 처리.
* **Cloudflare KV (`all_letter`)**: 500개의 따뜻한 격려 메시지(JSON 데이터)를 초고속 전역 분산 키-값 저장소에 저장 및 서빙.
* **Supabase (Auth & Database & Storage)**:
  * **Authentication**: 이메일/비밀번호 인증, 간편 로그인(Google, Naver, Kakao OAUTH) 및 실시간 유저 세션 관리.
  * **PostgreSQL (Database)**: 사용자 프로필(`profiles`), 획득한 편지 보관 정보(`user_letters`) 데이터 설계.
  * **Storage**: 달램이의 다양한 감정/행동을 담은 웹 이미지 에셋 및 사용자 프로필 이미지 호스팅.

## 🚀 핵심 기능 (Key Features)

### 1. 인터랙티브 로그인 & 회원가입 / 비밀번호 찾기
* **실시간 눈 가리기 애니메이션 (`character-secret.webp`)**: 
  이메일이나 비밀번호 입력창에 포커싱되거나 텍스트가 입력된 상태에서 달램이가 부끄러워하거나 안 보겠다는 듯 눈을 가리는 위트 있는 애니메이션을 적용하여 사용자의 몰입감을 높였습니다.
* **다양한 소셜 로그인 (OAUTH)**: 
  * Google, Naver, Kakao 로그인을 제공하여 본인 인증 단계를 간소화했습니다.
  * 중복 가입을 방지하고 최초 로그인 시 프로필 정보(이메일, 닉네임, 프로필 사진 등)를 Supabase DB에 자동으로 Upsert합니다.
  * 로그아웃 후 다시 재로그인 시 항상 계정 선택 및 인증 절차를 거치도록 보안 강화를 위한 프롬프트 설정을 적용했습니다.
* **이메일 인증 기반 회원가입 & 비밀번호 재설정**: 
  * 회원가입 시 실제 이메일 인증 절차를 완료해야 가입이 되도록 보안 로직을 설계했습니다.
  * 비밀번호를 분실한 사용자는 이메일 인증 절차를 통해 안전하게 신규 비밀번호로 재설정하고 바로 자동 로그인이 가능하도록 지원합니다.

### 2. 하루에 한 번 편지 받기 (출석체크 보상)
* **KST(한국 표준시) 기준 일일 편지 체크**:
  Supabase의 UTC 시간 정보를 KST(+09:00) 기준으로 계산하여, 사용자가 '오늘' 편지를 받았는지를 신뢰성 있게 판별합니다.
* **편지 오프닝 & 개봉 연출**:
  * 매일 최초 로그인 시 편지 수령 다이얼로그와 함께 편지 개봉 애니메이션이 수행됩니다.
  * 편지 상단 날개(세모 SVG 요소)가 180도 부드럽게 뒤집히면서 열리고, 하얀 편지지가 화면 위에서 아래로 스르륵 내려오는 실감 나는 효과를 연출합니다.
  * 따뜻한 감성의 캘리그라피 폰트인 **'나눔손글씨 펜 (Nanum Pen Script)'**을 웹폰트로 적용해 실제 손편지를 읽는 듯한 아날로그 감성을 더했습니다.
* **Cloudflare Worker & KV 연동**:
  * KV 스토어에 보관된 500개의 편지 모음 중, 사용자가 아직 받지 않은 편지 인덱스를 판별해 랜덤으로 하루에 1개씩 배정합니다.
  * 배정 완료 시 `user_letters` 보관함 테이블에 이력이 안전하게 영구 저장됩니다.

### 3. 달램이와의 실시간 상호작용 (Interaction)
* **Idle 동작 (20초 주기)**: 
  유저가 메인 화면에서 활성화된 채로 대기하면, 20초마다 달램이가 스스로 움직이며 혼자 노는 귀여운 연출을 수행합니다. (각 동작은 10초간 지속)
  * *도토리 먹기*: 1초 간격으로 `character-web-eat.webp`와 `character-web-eat2.webp`가 교차하며 맛있게 먹음.
  * *나비랑 놀기*: 나비 이미지와 놀다가(`character-enjoy.webp` 8초), 나비가 떠나갈 때 인사함(`character-enjoy2.webp` 2초).
  * *노래 부르기*: 1초 간격으로 춤추듯 마이크로 노래함(`character-sing1.webp`, `character-sing2.webp`).
* **마우스 클릭 & 드래그 인터랙션**:
  * *몸 클릭/드래그*: 간지러워하는 모습(`character-tickle.webp`)과 함께 전용 대사가 3초간 출력됩니다.
  * *머리 쓰다듬기 (머리 영역 드래그)*: 기분 좋은 표정(`character-happy.webp`)을 지으며 3초간 행복해합니다.
  * *머리 클릭 (도토리 주기)*: 도토리를 받아먹으며 감사 인사를 건냅니다.
* **도토리 스틸(Acorn Steal) 미니 게임**:
  * 달램이가 도토리를 먹고 있을 때 사용자가 도토리를 뺏을 수 있습니다(클릭/드래그 반응).
  * 뺏기면 슬픈 표정(`character-sad.webp`)을 지으며 5초 카운트다운이 시작됩니다.
  * 5초 이내에 다시 돌려주면 기쁘게 먹지만, 5초 초과 시 시무룩한 표정(`character-sad2.webp`)으로 바뀝니다.

### 4. 전체 편지 보관함 (Letter Archive)
* **500개의 편지 맵**:
  * 헤더의 편지 봉투 아이콘을 누르면, 1번부터 500번까지의 편지 전체 아카이브가 리스트 형태로 스크롤됩니다.
  * 이미 받은 편지는 흰색 카드로 표시되며, 클릭 시 귀여운 편지지 연출로 편지 원문을 다시 읽어볼 수 있습니다.
  * 아직 획득하지 못한 편지는 회색 카드로 비활성화 처리되며, *"아직 받지 않은 편지입니다. 출석을 할 수록 더 많은 편지를 얻을 수 있습니다!"*라는 힌트가 노출됩니다.
* **실시간 검색 및 필터링 컴포넌트**:
  * `SearchInput` 컴포넌트로 편지 번호(ID)나 편지 내용(텍스트)을 검색할 수 있습니다.
  * `SelectField` 컴포넌트 드롭다운을 통해 **'전체 편지'** 혹은 **'내가 받은 편지(내 편지)'**만 모아보기를 선택할 수 있습니다.

### 5. 마이페이지 (My Page) & 계정 관리
* **개인 정보 수정**: 닉네임, 취미, 특기, 성별, MBTI를 변경하고 Supabase DB에 동기화할 수 있습니다.
* **프로필 이미지 압축 및 업로드**:
  * 프로필 이미지 영역에 마우스 호버 시 연필 아이콘이 표시되어 이미지 변경이 가능합니다.
  * 파일 크기가 100KB를 넘는 경우 클라이언트 사이드에서 `browser-image-compression` 라이브러리를 사용해 100KB 이하로 자동 압축 후 Supabase Storage에 업로드하여 대역폭과 디스크 공간을 최적화합니다.
* **동네 주민 카운터**: 마이페이지 진입 시 가입일로부터 오늘까지의 날짜를 계산해 *"다람다람! 여기 오신지 벌써 n일이 되었습니다람!"*과 같은 스페셜 대사를 표시합니다.
* **회원 탈퇴 및 재가입(복귀) 지원**:
  * 탈퇴 시 달램이가 슬픈 표정으로 탈퇴를 만류하는 다이얼로그가 등장합니다.
  * 탈퇴를 확정하면 데이터가 완전히 삭제되는 대신, 프로필의 `is_active` 플래그가 `false`로 변하고 로그아웃됩니다.
  * 탈퇴 후 동일 계정으로 다시 로그인하여 복귀하면, 달램이가 감동하며 눈물을 흘리는 듯한 특별한 환영 메세지(`"다람다람! 다시 와주셔서 감사합니다람! 정말 기다리고 있었습니다람!"`)와 함께 `is_active`가 `true`로 자동 전환되며 정상 복귀됩니다.

### 6. 디테일한 편의 기능 및 감성 디자인
* **힐링 배경 음악 (BGM)**:
  * 웹 브라우저의 자동 재생 차단 정책을 우회하기 위해, 사용자가 로그인 완료 후 환영 팝업의 "알겠다람!"을 누르는 시점(사용자 상호작용 제스처)에 맞춰 감미로운 BGM(`main-bgm.mp3`)이 시작됩니다.
  * 헤더의 음표 아이콘을 눌러 언제든 BGM을 음소거/재생 전환할 수 있으며, 직관적인 커스텀 SVG 토글 아이콘이 반영되었습니다.
* **모바일 및 태블릿 반응형 웹 디자인**:
  * 모바일 기기 및 다양한 해상도에 대응하기 위해, 뷰포트 높이에 맞춤 처리하여 로그인 박스 및 달램이의 그래픽이 잘리지 않도록 CSS 비율을 미세 조정했습니다.
  * 화면 폭이 좁은 모바일/태블릿 환경에서는 헤더의 여러 아이콘 버튼들이 하나의 귀여운 도토리 아이콘(`acorn.webp`) 드롭다운으로 깔끔하게 통합되며, 푸터 등의 서브 텍스트 가독성을 최적화했습니다.

## 🗄️ 데이터베이스 및 데이터 구조

### 1. `profiles` 테이블 (사용자 프로필 및 출석 관리)
| 컬럼명 | 데이터 타입 | 제약 조건 | 설명 |
| :--- | :--- | :--- | :--- |
| `id` | `uuid` | Primary Key | Supabase Auth.users 외래키 연동 |
| `email` | `text` | Unique, Not Null | 사용자 이메일 주소 |
| `nickname` | `text` | Default: 이메일 앞부분 | 달램이가 사용자를 호칭할 때 쓰는 별명 |
| `avatar_url` | `text` | Nullable | 사용자의 커스텀 프로필 이미지 URL (Supabase Storage) |
| `last_check_in_at`| `timestamptz`| Nullable | 마지막으로 출석하여 편지를 수령한 시간 (KST 하루 1회 체크용) |
| `is_active` | `boolean` | Default: true | 회원 탈퇴 여부 플래그 (계정 비활성화 시 false) |
| `gender` | `text` | Default: '비밀' | 사용자의 성별 (남자 / 여자 / 비밀) |
| `mbti` | `text` | Default: 'infp' | 사용자의 MBTI 성격 유형 |
| `hobby` | `text` | Default: '' | 취미 |
| `specility` | `text` | Default: '' | 특기 |
| `created_at` | `timestamptz`| Default: now() | 서비스 가입 일자 (가입 경과 일수 계산용) |

### 2. `user_letters` 테이블 (사용자별 획득 편지 보관함)
| 컬럼명 | 데이터 타입 | 제약 조건 | 설명 |
| :--- | :--- | :--- | :--- |
| `id` | `bigint` | Primary Key, Generated | 편지 보관 내역 고유 번호 |
| `user_id` | `uuid` | Foreign Key (`profiles.id`) | 해당 편지를 수령한 사용자 ID |
| `letter_id` | `bigint` | Not Null | 획득한 편지의 고유 번호 (1 ~ 500) |
| `created_at` | `timestamptz`| Default: now() | 편지를 획득한 날짜 및 시간 |

### 3. `all_letter` JSON (Cloudflare KV 저장 편지 소스)
* Cloudflare Workers KV 스토어에 업로드되어 무중단 서빙되는 500개의 따뜻한 한마디 편지 데이터베이스 구조입니다.
```json
[
  {
    "id": 1,
    "message": "다람다람! 오늘도 당신은 누구보다 소중한 사람입니다람! 기운 내시길 바랍니다람!"
  },
  ...
  {
    "id": 500,
    "message": "다람다람! 힘든 하루였을 텐데 포기하지 않고 꿋꿋이 이겨내 줘서 고맙습니다람! 편히 쉬세요!"
  }
]
```

thanksquirrel/                     # 프로젝트 루트
├── frontend/                      # 리액트 웹 애플리케이션
│   ├── public/                    # 정적 리소스 (BGM, 파비콘 등)

## 💻 주요 화면 및 사용자 경험 (UX)

### 1. 로그인 / 회원가입 / 비밀번호 찾기 화면
* **첫인상**: 부드럽고 따뜻한 숲속의 힐링을 형상화한 배경화면(`background.webp`)이 채워지고, 창 뒤에서 달램이 캐릭터가 인사하며 환영합니다.
* **애니메이션 피드백**: 이메일이나 비밀번호 입력창에 커서를 두거나 글을 쓰는 타이밍에 달램이가 눈을 손으로 가리는 등 센스 있는 반응을 하여 로그인 과정을 하나의 놀이처럼 느끼게 합니다.
* **편의성**: 간편 로그인 버튼이 하단에 조화롭게 배열되어 있고, 모바일 가독성을 고려해 간격과 폼 크기를 반응형으로 줄여 가로세로 잘림 현상을 완벽히 방지했습니다.

### 2. 일일 편지 도착 및 오프닝 연출
* **등장**: 로그인 확인 시, 달램이의 반가운 안내 대사와 함께 편지 봉투가 부드럽게 화면 중앙에 생성됩니다.
* **개봉**: "알겠다람!"을 누르면 편지의 삼각형 덮개가 회전하여 열리며, 편지지가 부드러운 가속도로 미끄러지듯 스르륵 아래로 내려옵니다.
* **감성 텍스트**: Nanum Pen Script 특유의 손글씨 감성이 어우러져 한눈에 위로를 주는 메시지가 표기되고, 사용자가 다 읽고 "알겠다람!"을 누르면 BGM과 함께 드디어 평화로운 달램이의 숲속 메인 화면으로 이동합니다.

### 3. 메인 인터랙티브 숲속 화면 (Authenticated Home)
* **상주하는 달램이**: 화면 하단 푸터 바로 위에 기본 자세로 서 있는 달램이 캐릭터가 배치되어 언제든 유저를 반길 수 있도록 대기합니다.
* **헤더와 푸터**: 
  * 왼쪽에는 가로 400px 급의 널찍하고 귀여운 로고가 배치되며, 오른쪽에는 음소거 버튼, 편지 보관함 아이콘, 그리고 프로필 동그라미 아이콘이 존재합니다.
  * 해상도가 좁아지면 우측 헤더 메뉴가 깜찍한 도토리 모양 버튼 하나로 축소되어 원터치 모바일 편의성을 한층 향상시켰습니다.
  * 푸터 하단에는 심플하고 세련된 Copyright 문구가 정중앙에 정렬되어 있습니다.

### 4. 전체 편지 보관함 (Letter Archive List)
* **목록 표시**: 사용자가 매일 수집한 500개의 고유한 위로 메시지 리스트입니다.
* **진척도 확인**: 회색 비활성 카드를 통해 아직 받지 못한 편지들의 볼륨을 체감하며, 매일 로그인을 통한 수집(출석 보상) 욕구를 자극합니다.
* **검색 & 분류**: 다량이 된 카드 속에서 원하는 글귀나 특정 ID 번호를 빠르게 서칭하고, "내 편지만 보기" 필터를 통해 지난 힐링 메시지만 간추려 볼 수 있습니다.

### 5. 마이페이지 (Profile Settings)
* **개인화 공간**: 자신의 정보(취미, 특기, MBTI 등)를 달램이에게 알려주어 더욱 친근한 동네 이웃으로 등록되는 폼입니다.
* **친근한 웰컴 버블**: 가입 경과 일수를 알려주어 오랜 기간 함께한 교감을 텍스트 수치로 체감할 수 있습니다.
